# あまり探検！わり算パズル v3.5 数字専用AI判定版

## 今回の重要変更
- 数字0〜9の判定から汎用OCR（Tesseract）を外しました。
- 数字は、手書き数字専用の参照モデル（1797例）と比較するKNN方式で端末内判定します。
- 書いた数字を自動で切り出し、中央寄せ・大きさ正規化してから判定します。
- 数字判定はインターネット通信を必要としません。
- 「こ・まい・本・人」などの単位だけは、日本語OCRを別系統で使います。
- AIが数字を確信できないときは不正解にせず、どのマスかを指定して書き直しを案内します。
- v3.4の横長単位欄、大型数字欄、各マスの「消す」ボタンを維持します。
